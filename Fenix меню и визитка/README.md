# 🔥 Telegram-бот ресторана «FENIX RESTAURANT & BAR» (@Fenix_restaurant_bot)

Официальный Telegram-бот для ресторана и бара **FENIX** в Ташкенте. Разработан на основе всех предоставленных материалов заведения: дизайн-макета меню (8 страниц), визитки, фирменных логотипов, QR-кодов социальных сетей и фотографий блюд.

🔗 **Ссылка на бота в Telegram:** [@Fenix_restaurant_bot](https://t.me/Fenix_restaurant_bot)

## 🚀 Основные возможности бота

1. **📖 Интерактивное меню кухни и бара (188 позиций):**
   * **🇪🇺 Европейская кухня:**
     * Закуски (Селёдка, Холодец, Сельдерей с мясом, Лаваш с фетаксой/мясом, Язык в сливочном соусе, Наггетсы, Банкетные ассорти)
     * Салаты (Рубелла, Азиатский, Капри, Греческий, Цезарь с курицей/креветками, Мужской каприз, Оливье, Сельдь под шубой и др.)
     * Первые блюда (Чечевичный, Грибной, Солянка, Куриная лапша, Пельмени, Окрошка, Мексиканский суп)
     * Вторые блюда и стейки (Медальон, Рибай, Миньон, Телятина по-провански, Мясо по-французски, Карбонара, Альфредо)
   * **🍢 Кавказские шашлыки и мангал:**
     * Баранина, Говядина, Карбонат, Курица, Люля-кебаб
     * Маленькие шашлыки (Говядина, Лангет, Молотый)
     * Рыба на гриле (Форель, Скумбрия)
     * Овощи, грибы, кукуруза и картофель на мангале
   * **🇰🇷 Традиционная корейская кухня:**
     * Закуски (Ким-паб с сёмгой/мясом/креветками, Чапче, Эби темпура, Тубу кимчи, Токпокки с сыром)
     * Традиционные салаты и панчани (Косари, Мегича, Чука, Ве-ча, Хе из курицы, Рыба хе, Юк-хе, Кимчи, Древесные грибы)
     * Первые блюда (Кальбитанг, Юккедян, Твендянтиге, Кимчитиге, Хемультанг, Солонтанг, Кукси, Рамён, Том Ям)
     * Горячие блюда (Самгепсаль, Моксаль, Тёк-паль, Сями, Пулькоги, Хемуль покым, Пибимпаб, Пегоди)
   * **🍟 Гарниры и свежий хлеб:**
     * Картофель фри, по-деревенски, кукуруза, рис, тандырная лепешка, чесночные гренки
   * **🥤 Напитки и чай:**
     * Coca-Cola, Fanta, соки, домашний компот, вода Chortoq/BonAqua, авторские лимонады, чай
   * **🍸 Барная карта:**
     * Фирменные коктейли (Fenix, Kiss on the beach, Long Island, Мохито, Tequila Sunrise)
     * Элитный алкоголь (Виски Chivas/Jack Daniel's, Водка, Текила, Коньяк Hennessy/Ташкент ХО, Вино Bagizagan, Пиво)

2. **📸 Фотографии и оригинальные страницы меню:**
   * Ключевые блюда снабжены оригинальными иллюстрациями из дизайн-макета.
   * Функция «Просмотр страниц меню (1-8)» позволяет отправить любой разворот оригинального меню в виде изображения.
   * Кнопка «Скачать PDF-меню» моментально присылает оптимизированный документ `Fenix_Menu_Light.pdf` (6 МБ вместо исходных 286 МБ).

3. **🛒 Корзина с постоянным хранением в SQLite:**
   * Корзина привязана к пользователю в базе данных и не сбрасывается при отмене или бронировании стола.
   * Интерактивное редактирование количества (+1 / -1 / Удалить / Очистить).
   * Пошаговый мастер оформления:
     1. Выбор: Доставка курьером или Самовывоз
     2. Имя заказчика
     3. Номер телефона (с кнопкой быстрой отправки контакта)
     4. Адрес доставки (с поддержкой отправки геолокации через Telegram)
     5. Способ оплаты (Click, Payme, Наличные, Карта курьеру)
     6. Итоговая карточка заказа с номером заказа, списком блюд и суммой.
     7. Проверка часов работы (11:00 — 23:00).
     8. Мгновенная отправка заявки персоналу ресторана в Telegram.

4. **📅 Бронирование столиков (FSM-сценарий):**
   * Быстрый выбор даты (Сегодня, Завтра, Послезавтра или ввод вручную).
   * Выбор времени (12:00, 13:00, 14:00, 18:00, 19:00, 20:00, 21:00, 22:00).
   * Выбор количества персон (1-2, 3-4, 5-6, 7-10, Банкет 10+).
   * Выбор зала / зоны (Основной зал, Барная зона, VIP-кабинка, Любой стол).
   * Имя и контактный телефон гостя.
   * Сохранение брони в базу данных и отправка уведомления администраторам.

5. **📍 Локация и контакты:**
   * Отправка нативной геопозиции Telegram (`latitude: 41.275276, longitude: 69.352346`).
   * Кнопки с прямыми ссылками на Яндекс Карты и Google Карты для прокладки маршрута.
   * Отправка визитки контакта (`answer_contact`) для звонка в 1 касание на смартфонах.
   * Ссылки на Instagram и Telegram-канал.

6. **🔍 Умный поиск по меню:**
   * Кнопка «Поиск блюда» для точного поиска.
   * Автоматический поиск: пользователь может просто написать любое слово в чат (например: «шашлык», «кукси», «стейк», «том ям», «пиво»), и бот сразу выдаст найденные позиции с кнопками заказа!

7. **⚙️ Панель администратора и персонала (/admin):**
   * Вход по паролю: `/admin fenix`.
   * Авторизованные сотрудники получают автоматические уведомления обо всех заказах и бронированиях.
   * Просмотр последних заказов, броней, заявок на банкеты и финансовой статистики прямо в боте.

8. **🌐 Интеграция с официальным веб-сайтом:**
   * Кнопка «🌐 Наш веб-сайт» на главной клавиатуре и команда `/site`.
   * Поддержка Telegram WebApp (Mini App): сайт открывается прямо внутри Telegram!
   * Единая база данных `fenix_restaurant.db`: брони и заказы с веб-сайта автоматически попадают в базу и моментально отправляются авторизованному персоналу в Telegram.
   * Заявки на банкеты и свадьбы с сайта отображаются в разделе `/admin` -> «🎪 Заявки на банкеты».

## 🛠 Структура файлов проекта

```text
├── bot.py                  # Главный файл запуска бота (aiogram 3.28)
├── config.py               # Конфигурация (токен, пути, ID администраторов)
├── db.py                   # База данных SQLite (заказы, брони, корзины, персонал)
├── fenix_restaurant.db     # Файл базы данных SQLite
├── menu_data.py            # Структурированная база данных меню (188 блюд, цены, описания)
├── menu_data.json          # Экспорт меню в формате JSON
├── keyboards.py            # Все Reply и Inline клавиатуры бота
├── states.py               # FSM состояния (бронь, доставка, поиск)
├── utils.py                # Вспомогательные функции (безопасное редактирование, часы работы, оповещения)
├── run_bot.bat             # Скрипт быстрого запуска для Windows
├── handlers/
│   ├── start.py            # Команды /start, /help, /admin, главное меню
│   ├── menu.py             # Навигация по меню, карточки блюд, просмотр страниц
│   ├── cart.py             # Корзина и пошаговое оформление заказа
│   ├── reservation.py      # Пошаговое бронирование столиков
│   ├── contacts.py         # Локация, контакты, соцсети, отправка PDF-меню
│   └── search.py           # Поиск блюд по меню и умный перехват текста
├── img/                    # Папка с иллюстрациями блюд (1.png ... 30.png) и логотипами
├── menu_pages/             # Отрендеренные развороты страниц меню (page_1.jpg ... page_8.jpg)
├── Fenix_Menu_Light.pdf    # Оптимизированный PDF-файл меню (6.1 МБ)
└── 1. Menu fenix.pdf       # Исходный PDF-макет меню
```
